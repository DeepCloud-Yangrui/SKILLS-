# first-person-ai-story · 第一视角AI奇遇故事的创作引擎

## 这是什么

一个把"脑洞"变成"完整视觉连续故事"的创作引擎。

它解决的不是"怎么写出漂亮的画面"，而是另一个更硬的问题：**几十张画面之间，凭什么有因果关系**。

核心公式只有一句：

> **普通现实 + 一个无法解释的异常**

先建立可信的日常，再让异常一点一点渗进来。目标是让观众从"一开始只是想看看这个人遇到了什么"，走到"后来发现自己已经进入了这个世界"。

---

## 六阶段流程

在开工之前，先回答一组强制问题（脑洞是什么 / 最终真相是什么 / 真相会留下哪些痕迹 / 主角的日常 / 核心地点 / 视觉图腾）。缺一项就停下来，补齐再走。

| 阶段 | 做什么 | 落到哪个文件 |
|:---|:---|:---|
| 一 · 真相设计 | 从终点倒推起点：真相 → 痕迹 → 哪些痕迹可以提前出现 → 哪些细节后期要重新解释 | 异常升级表.md |
| 二 · 正常生活设计 | 起床、通勤、吃饭、刷手机——至少覆盖 5 项日常，让现实先立住 | 异常升级表.md |
| 三 · 异常升级表 | 把异常按七级排进画面，禁止跳级；每一级标注画面描述与核心信息 | 异常升级表.md |
| 四 · 视觉圣经 | 锁死人物、场景、道具、世界规则；再逐画面穷举"这一拍要用到哪些还没定义的东西" | 视觉圣经.md |
| 五 · 故事正文 | 按升级表逐画面写第一人称叙事，保留画面编号与异常层级 | 故事正文.md |
| 六 · 连续性检查 | 逐画面核对：有没有一图多信息、有没有跳级、有没有圣经外的新道具 | 回改以上文件 |

**七级异常阶梯**（这是整个引擎的骨架）：

1. 奇怪东西出现，但可能只是巧合 → 可以忽略
2. 再次出现 → 开始记住
3. 发生变化，出现新的异常 → 产生疑问
4. 异常开始针对主角，和生活产生联系 → 产生代入感
5. 出现明确证据（照片、记录、物品）→ 开始推理
6. 真相开始露出 → 接近答案
7. 认知反转，观众发现之前理解的一切可能错了 → 震撼

## 怎么调用

不需要记命令，用自然语言说清楚你要什么就行：

- 「我想写一个第一视角的 AI 奇遇故事，脑洞是：考研学生为省钱租了个便宜单间，从此每天凌晨三点十七准点自醒」
- 「帮我把这个脑洞做成一个视觉连续故事，先别写正文，先把异常升级表出来」
- 「我故事已经有了，帮我补一份视觉圣经」
- 「用第一视角奇遇故事的方法，把这三个文件放到 `<作品名>/` 目录下」

也可以直接用斜杠命令唤起：`/first-person-ai-story`。

---

## 产出物落在哪

所有产出会落盘成文件，不会只留在对话里：

```text
<项目根>/<作品名>/
├── 异常升级表.md   ← 节奏蓝图：七级升级 + 真相痕迹清单
├── 视觉圣经.md     ← 一致性基准：人物 / 场景 / 道具 / 世界规则 / 画面专属元素
└── 故事正文.md     ← 完整故事，保留【画面 N｜异常层级｜视角】编号
```

每个阶段一做完就落盘，不是最后一起写。文件已存在时先读旧内容再合并，不覆盖。

> **作品名**可以在开工前指定；不指定的话，会从脑洞里提一个 2–4 字的短名给你确认。

---

## 单独调用某一阶段

不是必须从零走完六步。缺哪块补哪块：

| 你说 | 会做什么 |
|:---|:---|
| 「我已经有故事正文了，帮我做异常升级表」 | 只跑阶段三，从正文倒推节奏 |
| 「帮我给这个故事做视觉圣经」 | 只跑阶段四，并做一次逐画面穷举 |
| 「检查一下这三份文件的连续性」 | 只跑阶段六，出问题清单不重写 |
| 「我只有一个脑洞，先帮我判断值不值得做」 | 用六个可行性问题先筛一遍 |

---

## 关键约束（这几条不能违反）

- **禁止跳级**：不许第二张图就出现最大奇观。异常必须逐级升级，中间一级都不能少。
- **一图一信息**：每个画面只承担一个核心信息，回答一个问题，同时制造下一个问题。
- **证据式叙事**：不许直接告诉观众结论。要展示老照片、记录、文件、痕迹，让观众自己推理。
- **手机随拍感**：构图不完美、光线不均、有杂物有噪点、人物不像模特。目标是"这个世界本来存在，只是主角刚好拍到了它"。
- **第一视角负责体验，第三视角负责交代**：探索、打开、翻看用第一视角；时代、全貌、人物关系用第三视角。

- **first-person-storyboard-review** —— 拿到分镜表之后，用它做质检（只挑毛病，不改东西）。
- **分镜生成** —— 目前**没有对应的 Skill**，故事转分镜这一环要靠人工或外部工具。这是整条链上唯一的缺口。
- 本 Skill **不产出分镜表、不产出生图提示词**，这两件事交给下游。
